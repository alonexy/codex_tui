## 模型与推理强度增补（2026-09-15）

- `/model` 菜单打开独立选择表单；模型来自本机桌面目录，推理强度随模型联动，使用中文标签并保留原生参数值。模型变更时选用该模型的目录默认强度，不沿用上一模型不支持的档位。
- `GET /api/models` 需要登录，仅返回模型展示字段、支持强度与同步时间；隐藏模型和内部提示词不返回。目录读取失败可重试，超过一天的目录标记可能过期，重读不会启动新 App Server。
- 设置按会话保留，用于后续 `turn/start` 的 `model`、`effort` 参数；执行中 `turn/steer` 不携带这些覆盖参数。确认发送成功后清除对应的下轮覆盖，失败保留，回执未知时显示待确认；旧回执不能清除后来保存的新选择。取消不修改已保存设置，消息草稿与图片保留。
- 每次打开并行读取模型目录和 `thread/read`（`includeTurns: false`）当前设置，优先使用 `thread.model`、`thread.reasoningEffort`；消费 `thread/settings/updated` 的 `threadSettings.model`、`effort`。旧读取不能覆盖新设置事件，其他会话、关闭后或重新打开前的迟到响应不能覆盖当前选择，桌面事件不能覆盖用户正在编辑的选择。
- 状态区区分当前会话、尚未发送的下轮设置和提交待确认；当前强度未知或读取失败时明确提示，不拿目录默认值冒充当前值。兼容 `/model 型号`；`/model default` 恢复首次连接的型号及该型号目录中的默认强度，不表示恢复首次连接时的自定义强度。
- 复验命令：`npm test` 和 `node scripts/model-picker-smoke.mjs`；浏览器脚本使用模拟 API，可通过 `PLAYWRIGHT_MODULE` 指定已有 Playwright。日志截图保存在本地 `output/playwright/model-picker/`。

## 待处理提醒增补（2026-09-15）

- 当前会话在输入区显示待批准、待回答数量和处理入口，点击定位请求；不主动打断阅读。其他会话在侧栏入口、项目及会话显示提醒，独立待处理列表覆盖搜索筛选外和未加载的会话。

## 手机优化回归

执行 `npm run test:mobile`。该脚本需要可导入的 Playwright 和本机 Chrome；也可将 `PLAYWRIGHT_MODULE` 指向已安装 Playwright 的 `index.mjs`。测试使用独立浏览器上下文和模拟服务，不连接真实桌面任务或读取访问密码。截图位于 `output/playwright/mobile-320.png`、`mobile-390.png`、`mobile-844.png`。

- 320、390、844 像素宽度；空闲与运行状态：按钮保持同一中心线、圆形、至少 44px，页面不横向溢出；输入与按钮之间至少 8px 间隔。
- 点命令菜单不聚焦消息输入；状态查询和参数表单保留草稿。
- 长文本自动增高；400px 高度模拟可用视口缩小时输入框有界，工具栏不重叠。
- 项目展开、收藏和组成部分选择在刷新后保留；新建摘要显示项目与完整工作目录。
- 发送已接收但响应丢失：恢复后查询原回执、补齐历史，消息仅一条，控制RPC不重发；丢失回执时保持阻止再次发送，允许手动核对后清除。
- 回执迟到仅清理当次提交的附件，保留之后添加的图片与其他会话草稿；旧会话失效和历史重载失败不阻断连接、游标更新或审批刷新，相关 Node 回归通过。
- 设备管理展示会话并撤销指定会话；真实鉴权、撤销立即失效及日志脱敏由 Node HTTP 集成测试覆盖。

浏览器尺寸/触摸模拟不能替代 iPhone 系统键盘、Safari 主屏幕模式、真实语音权限和弱网切换。真机验收仍需：打开/收起键盘、切换中英文输入法、锁屏一分钟后返回、切换 Wi-Fi/蜂窝网络，以及后台被系统回收后重新打开。
